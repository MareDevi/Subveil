日期：2026-10-20，Asia/Shanghai。

状态：云端协议适配与离线验证已落地；真实云端语音验收待凭据。范围止于 M03，未实施本地模型或独立文字翻译。

## 已实现

- 统一 Config / Provider / Recognition，保留音频驱动 Mock 与 Deepgram；新增阿里云、Google Gemini、火山引擎、腾讯云、百度、OpenAI、Azure OpenAI、xAI、自定义 DashScope、自定义 OpenAI Realtime。协议、速率、凭据与官方来源见 [cloud-services.md](cloud-services.md)。
- 删除此前可选本地后端、特性开关和原生模型依赖。本地模型导入、运行库与推理留给 M04。
- 显示接口自带译文，包括仍在修订的译文。原文与译文按 Session / Segment / revision 关联；过期、取消、旧修订与未知关联不会覆盖当前字幕。早到译文暂存；明确 Final 后不接受倒退。
- 自动识别源语言的服务不伪造 en / ja 检测标签；连续文字流使用 UTF-8 安全的有界滚动窗口，不伪造逐句 Final。xAI 按已提交语音回合绑定响应，百度 FIN 与下一句 MID 分离。
- 各协议分别处理鉴权、会话初始化、配置确认、PCM 封装和发送节奏。确认前不发送音频，重连清空积压；握手、写入、音频中断与响应等待均有超时，取消不必等待网络超时。
- PCM、原文、译文均使用有界队列；溢出丢最旧并计数。服务文本、关联 ID 和近期去重标识均有上限。采样率按服务能力选择，不统一固定为 16 kHz。
- 默认不联网、不上传。只有显式上传按钮或 CLI `--allow-upload` 才启用云端；缺凭据拒绝启动，无静默回退。错误不包含完整 URL、密钥、服务响应正文或识别文本。
- GUI 提供服务目录、选中态、源/目标语言、目标地址、显式启停和统计；运行时禁用服务与语言切换。返回音频不播放、不保存。诊断默认只输出统计。
