# M02 实施计划

日期：2026-10-20，Asia/Shanghai。

## 开始检查

- 工作区干净，main 与 origin/main 同步。
- Rust 1.99.1、rustfmt、Clippy 与 Linux 原生依赖检查通过。
- PipeWire 1.6.9、Wayland 会话可用；已有 pw-dump / pw-play / wpctl。
- 保持 GPUI 依赖不变。仅增加真实使用的音频平台边界。

## 范围与设计

- 显式开始/停止系统输出 monitor 捕获；不录文件、不联网、不实现 ASR。
- Linux 适配器监听默认 sink metadata 与 Audio/Sink registry，按 node.name 精确选择目标；没有输出时等待，不回退麦克风。
- 原生 PipeWire loop 在专用线程；回调仅复制有界 PCM，消费线程计算电平。UI 仅轮询快照。
- 请求单声道 F32LE；采样率由调用者指定，默认 48 kHz。使用 PipeWire 内置 sinc 重采样及混音，不重复实现低质量插值器。
- 预分配固定 PCM 块与有界队列；满时淘汰最旧块，累计丢块/丢样本。帧携带连接代次、序号、单调时间与采样率。
- 默认输出切换、节点移除时重建流；服务连接失败时有限频率重试，停止可取消。
- 控制窗口显示设备、采样率、RMS/峰值、静音、丢帧及错误；关闭窗口保留恢复入口。

## 验证

核心测试覆盖 PCM 边界、非有限值、队列溢出、时间与静音。执行 mise run check。
运行专用合成测试音与 monitor 检查；验证不同采样率、设备切换与恢复。30 分钟资源检查单独记录实际时长；不将短时运行声称为完整验收。
