# 字幕可读性与消费隔离修复

日期：2026-10-21。依据用户提供的 Subveil / Mimi / Sokuji 源码审查，优先处理前四项直接影响字幕主任务的问题。保留 Rust + GPUI、独立翻译 helper、显式上传授权及现有 CPU/GPU 边界。

## 实施约束

- 显示 TTL 只控制浮窗；匹配且仍在有界历史中的译文可补全历史。过期译文不重新抢占浮窗。接收截止仍由翻译 worker 控制。
- 浮窗最多显示两个句对：按片段顺序安排已完成译文的阅读位置，另一个位置用于最新原文。已进入阅读队列的译文至少保留 3 秒；有界历史淘汰仍优先于阅读，不能保证无限过载时零丢失。
- SenseVoice 持续消费、分段与同步 decode 分线程。最多保留两个等待段，过载淘汰最旧完整段，排队超过 1 秒的完整段也会丢弃；统计段数、时长及最近丢段范围。连续性变化使旧推理结果失效。
- 停止撤销上传、取消推理，保留已有记录，标记未完成翻译已取消；不排空最后未确定语音。清空记录为独立操作。新会话开始重置记录。
- 历史页面展示全部已保留条目及等待、失败状态。

## 后续独立工作

应用／播放流选择、语音 VAD 与分句、有限翻译上下文、首次配置、凭据存储、多屏、托盘、全局快捷键、断点续传及发布包需要各自的设计与平台验收。本次不把这些项目计为已实现。

## 验证

- `mise run doctor`：Rust 1.99.1、rustfmt、Clippy 及本机原生依赖检查通过。
- 核心与 ASR 定向测试通过。新增 6 项回归测试：9 秒译文在 8 秒显示 TTL 后仍补历史、旧 revision / 会话 / 淘汰条目拒收、持续新原文期间阅读位置保持、多个已完成句对依次获得 3 秒、停止保留及取消、慢 decode 时 PCM 持续消费并统计完整丢段。已有过期译文测试同步改为只补历史。
- `mise run check`：格式、工作区构建、严格 Clippy、99 项测试通过。最初沙箱内下载器 HTTP 测试因不能绑定本机端口失败；允许本机端口后全量通过。
- Wayland GUI：使用隔离 `/tmp` 配置运行离线演示 5 秒并截图；控制窗口、原文、完整译文和浮窗可见。没有采集、模型下载或云端上传。启动及截图只作为冒烟验证。
- 双句对调度、停止／清空、全部历史滚动的 GUI 点击与键盘验收尚未完成；双句对时间验证来自纯状态测试，不代表测量了显示器实际呈现时长。
- SenseVoice 慢推理验证使用注入 decoder，未重新进行真实模型质量／吞吐测试。原生 decode 不支持抢占取消，后台 worker 可能等当前调用返回，GUI 不等待。
- 尚未验证长期稳定、显示覆盖率、极大字体下的小屏裁剪、多 compositor、多 GPU、游戏并行功耗。单次测试不超过 90 秒。
