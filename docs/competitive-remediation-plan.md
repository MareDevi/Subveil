## A：可靠性结果

GGUF helper 改为独立写线程、容量 1 请求通道；父 worker 的取消与期限不再等待 stdin。真实 helper 传输回归注入 2 MiB 阻塞写，确认取消/超时后释放进程。默认生产请求仍限制 64 KiB。

云握手保留安全 HTTP 状态分类；401/403 及无效配置停止重试，429 尊重数字 Retry-After（超过 60 秒要求用户稍后重新开始），临时故障最多四次 1/2/4/8 秒退避。JSON 服务错误只匹配白名单错误码，不保留消息正文；未知错误按临时故障处理。连续连接 30 秒后恢复重试预算。

`mise run doctor` 与 `mise run check` 通过。新增三项回归；最初定向 HTTP 测试受沙箱回环监听限制，允许本机监听后同命令及完整门禁均通过，未跳过测试。未使用真实云凭据。

## B：翻译调度结果

- Final 独立容量 8 队列、预览 latest-only 容量 1；预览不能挤掉 Final。HTTP 预览在 Final 到来时取消。
- GGUF stdin 独立读取取消消息；推理按输入 batch/token 检查取消，父进程最多等待两秒取消确认，超时终止并显式报错。取消无需重载模型；不支持抢占单个原生 decode 内部。
- HTTP 和本地共享按 session/源语种/目标语种隔离的三句源文上下文；排除草稿、当前段与未来段，每句最多 1024 字符。本地超 token 预算先缩参考历史，不截当前字幕。
- 本地/OpenAI-compatible 可在语音服务填写最多 4096 字节术语表。内容作为数据发送，不拼接进系统指令；可随其他服务设置显式保存到密钥环。
- 核心容量 1 Signal 驱动 GPUI 异步结果消费；ASR 与翻译结果不再必须等 250 ms 统计定时器。主线程繁忙仍可能延迟，不宣称已测屏幕呈现时间。
- `mise run check` 通过。新增上下文隔离、Final 优先、原生预览取消、Signal 合并回归。取消消息与初始写入争用容量 1 时曾失败，已以非阻塞重试修复，未扩大队列绕过问题。
- 已安装 Qwen2.5 1.5B CPU helper 真实短测：取消确认 487 ms；同一个进程随后完成带历史/术语的否定句翻译。只记录成功、否定与耗时，不保存译文。没有上传或采集音频。

## C：语音检测与分块结果

- 新增固定 revision 的 Silero VAD 1.8 MB 安装项，源为 `csukuangfj/vad`，MIT；`fba88cd2e921609e7675c3aaf51e0b9b295da4bc`，SHA-256 `a35ebf52fd3ce5f1469b2a36158dba761bc47b973ea3382b3186ca15b1f5af28`。模型库显示来源与许可，显式安装后启用；保留能量模式。适用于 SenseVoice/Whisper 离线分段，不替代 Zipformer 原生端点。
- 使用锁定 sherpa-onnx 1.13.8 CPU VAD，16 kHz、512 样本窗口，阈值 0.5；静音/最短/最长语音来自现有分段参数。配置缺失或损坏时明确失败，不静默退回能量检测。队列与音频连续性重置仍有效。
- Whisper 仅对音频连续块增加 400 ms 回看；仅在上一个结果确实被接收且时间相邻时做最长 80 字符的精确后缀/前缀去重。少于四字符不删除，断开或丢段不按文本猜关联。这是保守回看，不是词级时间戳对齐，也不代表边界识别质量已经全面解决。
- 阅读位置按译文字符量分配 3–10 秒，保留原来的有界历史和双位置；尚未实现相邻短句合并，不能承诺过载时所有译文都被读完。
- 临时目录真实安装验证成功；已有公开英文 WAV 经 Silero + SenseVoice CPU 返回一段 Final，推理 178 ms / 段音频 5438 ms，重置/丢音频/丢事件均为 0。没有采集系统声音或上传。此结果不等于音乐背景/多语种准确率评估。
- `mise run check` 通过。新增神经 VAD 不可用时拒绝回退、跨块回看/Unicode 去重、长译文阅读预算回归。日语 Fujie 候选 API 本次仍返回 401，继续寻找可验证来源，不加入伪可用目录。

## D：音源隔离结果

- 原生实时页新增音源下拉与刷新：默认输出、指定输出、指定输入节点、单个应用播放流。枚举只读取元数据；采集仍需显式开始，云上传仍单独授权。
- 选择绑定 PipeWire server cookie + object serial + 节点类别；不依赖会复用的 global ID。所选节点消失时停止该流输入，不改采默认混音；恢复需用户刷新并重新选择。
- 应用播放流使用显式 PipeWire links 复制到私有采集输入，不移动应用原有路由，不创建全系统混音回退。仅支持单/双声道；更多声道明确拒绝。回调用固定栈缓冲进行立体声下混。
- 新增 `mise run audio:isolation`：独立临时空输出上同时产生 440 Hz 和 1000 Hz 两路合成流，只选择前者。实测收到 95232 样本，目标/另一频率功率比 42468700.4；移除目标后另一流继续运行，断开阶段非零样本为 0。未采集私人音源、未保存音频；测试结束销毁临时节点。
- `mise run check` 通过。新增 ID/服务器重用拒绝与下混非有限值回归。实际麦克风、所有物理输出、六声道、服务重启和 GUI 点击选择还需在后续交互验收逐项记录。

## E：配置与主流程结果

- 实时页直接配置音源、服务档案、源/目标语种、ASR 与独立翻译，展示实际链路和就绪缺项。开始按钮分别说明本地、模拟、音频上传；文字上传仍独立授权。
- 原来的语种、模型、设备和 Whisper 块长循环按钮改成可见下拉。适配器能力与本地模型语言约束共同决定选择；当前保守开放中/英/日，不把服务营销语言清单当作适配完成。GPU 名称仅是选择项，加载失败不回退 CPU。
- 最多 32 个命名配置，保存服务、翻译、语言、目标与音源生命周期标识。选定流不能跨 PipeWire 重启自动绑定同名新流。上传授权不持久化；切换档案撤销授权。凭据按配置隔离，默认配置保留旧版 Secret Service 属性。增加重名、无效选择、源恢复和密钥环属性隔离回归。
- 修复恢复时本地模型把已保存云配置覆盖的问题。应用提示 `secret-tool` / 会话总线就绪情况，不以工具存在声称密钥环已解锁。
- 增加 GPUI Kit 生产 ControlView 集成测试，真实鼠标及键盘事件验证运行中拒绝清空、停止保留、清空、导航与焦点恢复。测试不构造替身 View，不连接硬件或云。测试能力所需平台依赖同时锁定兼容的 cocoa 0.26.0、unicode-properties 0.1.3；没有切换应用 GPUI 类型来源。
- 此项不等于完整 GUI、屏幕呈现时间、读屏和真实云账号验收；这些继续在 F 跟踪。
