# Zed 风格原生界面重构

日期：2026-10-24。范围：全部控制页、恢复入口及应用主题；继续使用 Rust + GPUI Kit 0.8.0。

## 调研

检查时工作区干净，分支为 main，Rust 1.99.1；`mise run doctor` 通过，Wayland 和 X11 显示环境可用。已读取 GPUI Kit Design Guides、Coding Guides，通过 Context7 查询 `/longbridge/gpui-kit`，并以本机 0.8.0 发布源码核对接口。

参考 https://zed.dev/ 的实际页面与产品截图：深石墨背景、相邻面板的低对比层次、细分隔线、紧凑工具栏、持续可见的导航和状态栏，蓝色仅用于选择与关键操作。借用其布局语言，不复制商标、网站营销内容或编辑器专用功能。

补充阅读 https://gpui-kit.com/base/ 及 Getting Started：Base 提供行为、状态、焦点和主题 token，Component 在其上提供可直接使用的呈现。保留标准控件的行为与无障碍语义，由应用拥有布局和配色。不是把现有控件全部改写成自绘 div。

配色扩展为石墨、靛蓝、沙丘三组，各含深浅两套。通过 `Theme::change` 初始化模式，再通过 `Theme::update` 同步 Component 的 colors、paint tokens 和 Base 投影，避免滚动条或弹层残留旧主题。选择写入 `interface_theme`，随显式保存样式持久化；旧配置默认石墨深色。明暗快捷键切换同组对应方案，不重置配色家族。切换应用配色不重建字幕浮窗。

## 设计约定

- 主任务是开始字幕会话并阅读双语结果。预览优先显示；会话配置与历史保持明确分区。
- 顶部工作区栏、左侧工具导航、主区标签栏、底部真实状态组成固定框架。设置内容独立滚动。
- 主题集中定义三组、六套语义配色。组件只读取主题；圆角收紧，不添加卡片阴影或装饰渐变。
- 文字采用系统字体，元数据次级显示；行、标题、工具栏共用对齐线。使用 rem 间距与组件 small 尺寸。
- 服务、模型、样式、诊断采用一致的分区标题和属性行。服务按识别、翻译、凭据分成三页；模型按识别、翻译、VAD、维护分成四页。来源、许可证、目标地址、错误和取消入口保留。
- Session 持有业务状态；ControlView 持有导航、焦点与滚动位置。不得在 render 中创建实体或启动业务操作。
- 保留 Ctrl+1–5、Ctrl+B、Ctrl+Shift+O、Ctrl+S、Ctrl+Shift+L 和恢复窗口 Enter。切换导航恢复工作区焦点。
- 上传仍需现有明确授权；不因改版自动采集、下载、调用云端或持久化字幕。
- 保留系统窗口装饰、独立字幕内容样式和关闭后的恢复入口。默认 1120×800，最小 760×560；窄窗口将次要区域换行。

## 验证结果

- `mise run check` 通过：格式检查、Workspace 构建、所有目标严格 Clippy，以及 147 项测试通过。单次测试运行由 90 秒超时保护。
- 沙箱首次运行时拒绝模型下载测试的回环 HTTP 监听；解除沙箱限制后完整重跑通过，未修改测试来绕过检查。
- 新增生产控件交互测试覆盖六套配色、Component / Base token 同步、同组明暗切换、显式保存与读取、切换配色不启动采集或重建浮窗，以及 760×560 最小窗口的开始入口和预览可见性。现有停止、历史、焦点恢复、模型搜索、下载来源显式应用与许可证取消测试保持通过。
- 独立运行 `mise exec -- timeout 90s cargo test --locked -p subveil render_workspace_review_images -- --ignored --nocapture` 通过。使用系统文字整形和真实 GPU 光栅化，生成六套配色 × 五个页面，以及服务三页、模型四页，共 37 张截图并审阅。修正配色按钮内容裁切，统一为三列两行。截图仅存放于 `/tmp/subveil-ui-review`，不提交仓库。该测试依赖图形渲染器，常规检查中保留为 1 项忽略测试。
- 在本机 Wayland 会话运行 `--demo` 12 秒，使用临时配置路径，随后由 `timeout` 结束（退出码 124）。未出现应用窗口创建错误或 panic；Vulkan 日志显示本机 LSFG 隐式层加载失败并被跳过。此项只验证启动与短时存活，不等同于完整交互验收。

## 限制与后续

原生窗口的人工鼠标操作、多显示器、屏幕阅读器、系统缩放、其他 compositor 和长时稳定性未验证。本轮未重新验证 ASR、翻译推理或 GPU 推理能力；界面截图中的字幕来自离线 mock，不代表真实识别结果。字幕浮窗保留现有独立内容配色、显示模式与平台能力边界。
